# Used-Car-Price-Predection-and-Market-Trend-Analysis-Using-Data-Analytics
A data-driven capstone project analyzing 15,411 Car Dekho listings. Features EDA via Python &amp; Power BI , data cleaning , and price optimization models. Implements Linear Regression (R^2: 0.80) and Random Forest Regressor (R^2: 0.88) to evaluate depreciation trends and accurately predict pre-owned vehicle valuations.
